# 戦闘ルール

戦闘は、スクエア状のマップ上で行われます。
各キャラクターはマスに配置され、移動や攻撃を行います。

本章では、戦闘の進行手順と、戦闘中に使用される基本的なルールを説明します。

## 22.1 戦闘の基本

戦闘は、以下の要素によって構成されます。

- ラウンド
- ステップ
- アクション

## 22.2 戦闘開始

戦闘が開始されると、以下の手順を行います。

1. 戦闘に参加するキャラクターを決定する
2. 各キャラクターをマップ上に配置する
3. ラウンドを開始する

## 22.3 ラウンドとステップ

戦闘はラウンド単位で進行します。

ひとつのラウンドは、以下のサイクルで構成されます。

1. スタートステップ
2. ターンステップ
3. アクションステップ
4. (未行動のキャラクターがいない場合)エンドステップ

## 22.4 スタートステップ

ラウンド開始時、スタートステップを行います。

このとき、スタートステップで使用できるとくせい、へんかわざを宣言できます。すばやさの高いキャラクターから順に宣言し、すべてのキャラクターが宣言を行ったら、すばやさの高いキャラクターから順に宣言した内容を処理していきます。すばやさが同じキャラクターがいた場合は、PCの中で任意の順番で処理した後、NPCの中で任意の順番で処理を行います。

## 22.5 ターンステップ

未行動のキャラクターの中から最もすばやさの高いキャラクターが、次にアクションステップを行う権利を得ます。すばやさが同じキャラクターがいた場合は、PCの中で任意の順番で処理した後、NPCの中で任意の順番で処理を行います。

このとき、ターンステップで使用できるとくせい、へんかわざを宣言できます。すばやさの高いキャラクターから順に宣言し、すべてのキャラクターが宣言を行ったら、すばやさの高いキャラクターから順に宣言した内容を処理していきます。すばやさが同じキャラクターがいた場合は、PCの中で任意の順番で処理した後、NPCの中で任意の順番で処理を行います。

未行動のキャラクターがいなければ、エンドステップへ移ります。

## 22.6 アクションステップ

ターンステップで権利を得たキャラクターはアクションステップを行います。アクションステップでは、3つのアクションを順番に行います。

1. ムーブアクション
2. マイナーアクション
3. メジャーアクション

### 22.6.1 ムーブアクション

ムーブアクションでは、**通常移動**または**全力移動**でキャラクターを移動させることができます。このとき、ほかのキャラクターがすでに存在するスクエアに移動させることはできません。ただし、同じ陣営のキャラクターの存在するスクエアを通過することはでき、また、違う陣営のキャラクターの存在するスクエアは通過することができません。

また、**通常移動**や**全力移動**のかわりに、ムーブアクションで使用できるとくせい、へんかわざを使用できます。

**通常移動**

キャラクターを今いるスクエアから別のスクエアに移動させることができます。縦横に1マスの移動を1移動とし、最大で3移動することができます。

**全力移動**

キャラクターを今いるスクエアから別のスクエアに移動させることができます。縦横に1マスの移動を1移動とし、最大で6移動することができます。

### 22.6.2 マイナーアクション

マイナーアクションでは、マイナーアクションで使用できるとくせい、へんかわざを使用できます。

### 22.6.3 メジャーアクション

メジャーアクションでは、攻撃わざ、またはメジャーアクションで使用できるとくせい、へんかわざを使用できます。

### 22.7 エンドステップ

ターンステップで未行動のキャラクターがいない場合、エンドステップを行います。エンドステップでは以下の処理を行います。

1. すばやさの高いキャラクターから順に、ターンステップで使用できるとくせい、へんかわざを宣言できる。
2. すばやさの高いキャラクターから順に、宣言したとくせい、へんかわざを使用する。
3. 状態異常の処理を行う。
4. 行動済みのキャラクターは未行動となる。

## 22.8 攻撃とダメージ

### 攻撃の手順

1. 使用するわざを宣言する
2. 命中判定を行う
3. 成功度を算出する
4. ダメージを算出する

### 命中判定

- 攻撃は、原則として攻撃側のみが行為判定を行います
- 対象は回避判定を行いません

技の種別によって命中判定に用いる能力値が決定します。

|種別|能力値|
|--|--|
|ぶつり|こうげき|
|とくしゅ|とくこう|
|へんか|（わざタグによる）|

成功度が1以上であれば攻撃は命中したものとし、ダメージ算出を行います。

### ダメージ算出
```
ダメージ ＝（威力＋成功度）d6
```
- 威力は、わざの基本ダイス数です
- 成功度が高いほど、振るダイスは増えます
- とくちょう、とくせい、わざタグの影響でさらなる補正がかかる場合があります

## 22.9.1 防御とダメージ軽減

ダメージが算出された後、対象は防御による軽減を行います。

- ぶつりわざ：ぼうぎょを使用
- とくしゅわざ：とくぼうを使用
```
算出ダメージ ＝ ダメージ − 防御値
```

算出ダメージは 0 未満になりません。(最低で1となります)

## 22.9.2 タイプ相性

防御による軽減を適用後、タイプ相性による補正を行います。わざのタイプが、攻撃を受けたキャラクターの弱点や耐性であった場合、算出ダメージに修正を行います。

|相性|処理|
|--|--|
|弱点（+2ｄ）|2ｄを振り、ダメージに加えます|
|弱点（+1ｄ）|1ｄを振り、ダメージに加えます|
|耐性（1/2）|ダメージを半分にします（端数切り捨て）|
|耐性（1/4）|ダメージを4分の1にします（端数切り捨て）|
|耐性（1/10）|ダメージを10分の1にします（端数切り捨て）|

また、耐性による修正によってダメージは 0 未満になりません。(最低で1となります)  
このように修正を加えたダメージを最終ダメージとして、対象となったキャラクターのHPから減少させます。HPは最低0であり、HPが0になったキャラクターは**きぜつ**して、行動ができなくなります。

## 22.10 戦闘の終了

下のいずれかを満たした場合、戦闘は終了します。

- 敵対する勢力のいずれかが戦闘不能になった
- 戦闘の継続が不可能、または不要になった
- ゲームマスターが戦闘終了を宣言した
